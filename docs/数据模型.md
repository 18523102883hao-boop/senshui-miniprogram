# 数据模型（云数据库集合）

金额单位统一为**分**。时间统一 `Date` 类型。用户身份统一以 `_openid` 关联。

> ★ = V1 本轮已使用；☆ = 下一阶段 / V2 预留

---

| 字段 | 类型 | 说明 |
|---|---|---|
| _openid | string | 微信 openid（云函数内手动写入） |
| unionid | string | 开放平台 unionid（可空） |
| phone | string | 手机号（授权后写入） |
| nickName / avatarUrl | string | 昵称头像（可空） |
| createdAt / updatedAt | Date | |

## members ★（会员卡）
| 字段 | 类型 | 说明 |
|---|---|---|
| _openid | string | 持卡人 |
| memberCode | string | 会员码（唯一，供核销扫码）；建**唯一索引** |
| status | string | active / refunding / refunded / paid_dup |
| birthday | string | 生日 `MM-DD`（购卡必填，用于生日 85 折权益）（T20） |
| benefits | object | `{ ling:{total,granted:bool}, birthday:{discount:0.85} }`（T20 去酒/券，改生日权益） |
| orderId | string | 关联 orders.outTradeNo |
| activatedAt / expireAt | Date | 开卡时间 / 到期（+365 天） |

> **权益说明（T20）**：长河令为一次性到店发放（`ling.granted`）；生日 85 折为生日当天可反复核销、不设 granted，核销仅在 `verifications` 留痕。会员码升级为**动态码**（`getMemberQr` 生成 90 秒时效 token），防截图转让。

## home_configs ★（首页模块配置，本轮新增）
| 字段 | 类型 | 说明 |
|---|---|---|
| version | number | 版本号，取最大值生效；`seedPortalContent --force` 递增 |
| sections | array | 模块数组，见下 |
| updatedAt | date | 更新时间 |
| updatedBy | string | 更新人 openid |

`sections[]` 字段：`key`（唯一标识）、`type`（hero / quick_entry / primary_action / user_status / service_card / member / activities / map / footer）、
`title`、`subtitle`、`imageFileId`、`route`（绝对页面路径，空串表示本地渲染不跳转）、`params`（跳转参数对象）、
`visible`（false 即隐藏）、`sort`（升序，10 递增便于插入）、`startsAt` / `endsAt`（生效时间窗，可空）。

> 云端无配置或读取失败时，`getHomePortal` 回退到 `portal-core.js` 的 `DEFAULT_SECTIONS`，首页不白屏。

## 领域状态常量（单一真源）

以下取值的**唯一定义处**是 `miniprogram/utils/domain.js`，云函数各自复制时必须与此表一致；
契约由 `tests/feature-expansion/contracts.test.js` 锁定，改动状态值会导致该测试失败。

| 常量 | 取值 | 来源 |
|---|---|---|
| `ORDER_TYPES` | `member_card`、`ticket_upgrade`（已上线，不可改）、`ticket_order`（新增）、`rental_order` / `retail_order`（预留） | PRD §14.4 |
| `TICKET_STATUS` | `unused`、`reserved`、`used`、`refund_pending`、`refunded`、`expired`、`void` | PRD §8.6 |
| `VISIT_RESERVATION_STATUS` | `pending`、`confirmed`、`completed`、`cancelled`、`rejected` | PRD §17.6 |
| `LEAD_STATUS` | `new`、`contacted`、`qualified`、`proposal`、`won`、`lost`、`closed` | PRD §12.4 |
| `FEEDBACK_STATUS` | `submitted`、`processing`、`resolved`、`closed` | PRD §15.2 |

**金额约定**：全站金额一律以「整数分」在前后端流转，元只出现在展示层，由 `domain.js` 的 `fenToYuan()` 转换；
该函数对非整数分（如 `9.9`、`'990'`）直接抛错，防止浮点元被误写进订单。

**本轮新增集合**（集合名已登记在 `miniprogram/utils/const.js` 的 `COLLECTIONS`，字段随各任务落地时补充到本文档）：
`home_configs`、`articles`、`ticket_products`、`tickets`、`visit_reservations`、`service_leads`、`feedback`、`itineraries`。
门票订单复用 `orders` 集合，以 `type: 'ticket_order'` 区分（PRD §17.4）。
