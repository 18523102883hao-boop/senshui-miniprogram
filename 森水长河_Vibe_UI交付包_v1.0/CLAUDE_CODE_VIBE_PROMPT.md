## 二、目标风格

森水长河应呈现“自然探索 + 森林水岸度假 + 轻奢户外 + 沉浸江湖游戏”的统一体验。

- 向导、地图、预约、商城、我的：米白自然浅色主题。
- 长河令、悬赏、拍卖、侠客资产：极暗沉浸主题。
- 参考优秀 App 的光影、数据卡片、触觉反馈和无按钮化交互，但绝不复制其品牌视觉。

## 三、必须落地的 UX 变化

### 1. 整卡可点击

任务、活动、商品、路线、订单列表项都把整个容器作为触摸区。只有支付/预约确认/取消等关键操作保留独立按钮。

### 2. 物理压感

- 普通卡片按压：scale(.96)，100–140ms。
- 主 CTA：scale(.94)，100–120ms。
- 使用 `hover-class` 或组件内部 pressed state，避免触摸结束后卡住。

### 3. 触觉反馈

封装统一 `haptic()`：

- 普通选择：light。
- 领取长河令、预约成功、支付成功：medium。
- 取消/风险确认：heavy。
- 不要在每次 touchstart 都振动；只在动作被系统接受时振动。

### 4. 长河令深色模式

- 页面背景 `#121212`。
- 资产卡 `#1C1C1E`，使用两个绝对定位的 radial-gradient 弥散光层，不依赖伪元素。
- 余额数字 72–88rpx / 800–900；金色只用于奖励与资产。
- 悬赏列表整项点击，取消“去完成”按钮。

### 5. 动态底部导航

实现自定义 tabBar：

- 浅色页：米白半透明 + 模糊；深色页：黑色半透明 + 模糊。
- 主题切换 240–320ms。
- 选中图标使用 `assets/icons/tabbar/*-active.png`；未选中使用 `*-default.png`。
- 选中图标 scale(1)，未选中 scale(.90–.94)；标签淡入淡出。
- 如果当前渲染引擎不稳定支持 blur，提供高透明度纯色降级方案。

### 6. 地图使用半屏卡片

点击 POI 后，不立即跳新页面。显示上滑半屏卡片：地点简介、距离、营业状态、导航、详情、打卡。用户再次点击“详情”才进入完整页。

### 7. 横滑选择

日期、预约时段、活动分类、商品分类采用横向 scroll-view；有吸附感和选中状态，不使用拥挤下拉框。

### 8. 长按交互

- 长按长河令任务：预览奖励规则。
- 长按兑换商品：预览大图和所需令数。
- 长按领取动作需 450–600ms，并显示进度环，完成后再振动。

## 四、视觉令牌

不得自行新增色值，优先使用：

```text
bg-light       #F6F4F0
surface-light  #FFFFFF
text-primary   #172019
text-secondary #7D867F
forest         #244B36
forest-deep    #173628
moss           #3A6749
gold           #D5A43A
coral          #F07055
mist           #E9EEE8
bg-dark        #121212
surface-dark   #1C1C1E
success        #36B66A
```

圆角：24 / 32 / 40 / 56rpx 四档。页面边距 32rpx；基础网格 8rpx。

## 五、图标接入

- 图标资源在 `assets/icons/`。
- 浅色页：`assets/icons/forest/`。
- 深色页：`assets/icons/ivory/`。
- 状态：`assets/icons/status/`。
- 底部导航：`assets/icons/tabbar/`。
- 路径和用途以 `icon-map.json` 为唯一映射表。
- 删除 Emoji 和临时字符图标，不使用运行时网络 iconfont。

## 七、工程约束

- 复用现有数据层、云函数和业务状态，不改变已验证的支付/订单/预约逻辑。
- 不使用 CDN 外链字体、外链图标或网页端 Tailwind。
- 微信原生小程序使用 WXML/WXSS/JS/TS 的现有技术栈；不要把 HTML Demo 直接塞入 web-view。
- 尽量使用组件化：`vibe-card`、`glow-card`、`status-chip`、`bottom-sheet`、`custom-tab-bar`。
- 动画只使用 transform/opacity，避免频繁改变布局属性。
- 支持低端安卓机；滚动列表中禁止大量实时 blur 和阴影。

## 八、验收标准

- 首屏 10 秒内能回答：园区是否开放、天气/水位、最近活动、我的预约、核心入口。
- 所有关键交互都有按压态；成功操作有合理触觉反馈。
- 长河令页与浅色页主题明显不同但品牌统一。
- 底部导航切换无闪白、无跳动、选中态清晰。
- 关键文字对比度足够；字号不小于 22rpx。
- 无 Emoji 图标、无临时占位、无随机色值。
- 真机连续切 Tab、快速滚动、频繁点击不掉帧、不重复提交。
