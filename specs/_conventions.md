# 全局约定（所有任务通用）

## 1. 云函数返回格式
统一 `{ code, msg, data }`：
- `code`：0 成功，非 0 业务错误（401 未登录、403 无权限、404 不存在、409 冲突/重复、400 参数错、500 内部错）
- `msg`：错误提示（可直接 toast）
- `data`：成功负载

**例外**：`payCallback` 是微信支付回调，必须返回 `{ errcode:0, errmsg:'SUCCESS' }`，不走上面格式。

## 2. 前端调用
统一用 `miniprogram/utils/request.js`：
```js
const request = require('../../utils/request.js')
request.call('funcName', { ...params })            // 返回 Promise<data>，失败 reject(Error)
request.callWithLoading('funcName', {}, '加载中')    // 带 loading
```
云函数 `code!==0` 会被转成 `reject(new Error(msg))`，页面 `.catch` 处理。

## 3. 身份与鉴权
- 用户身份用 `cloud.getWXContext().OPENID`，**不信任前端传入的 openid**。
- 员工操作前必须 `checkStaff`（status='approved'）；核销/插单等敏感操作在**云函数内**再校验一次角色，不能只靠前端隐藏入口。
- 手机号授权延后到预约/下单节点（省授权组件调用成本），不在进入即索取。

## 4. 数据规范
- 金额单位：**分**（int）。前端展示用 `util.fen2yuan`。
- 时间：`Date` 类型。
- 集合权限：设为「所有用户不可读写」，一切读写经云函数（管理员身份绕过规则）。
- 幂等/防重：涉及钱与库存的写操作必须用**事务** + **唯一索引**双保险（见 `docs/数据模型.md`）。

## 5. 弱网 / 离线（户外信号差）
- 静态内容本地缓存；会员码/预约码生成后 `wx.setStorageSync` 持久化，离线可出示。
- 图片分级压缩加载；关键操作失败要有重试与友好提示。

## 6. 合规红线（长河令 · 生死线）
**统一用语**：`奖励令数`（赚）/`参与令数`（用）。
**全站禁用词**（前后端 + 文案 + 客服话术）：
> 押注、下注、翻倍、稳赚、稳赚不亏、以小博大、赌、博彩、抽奖概率承诺

其他约束：
- 拍卖仅作**介绍**，不做线上竞拍；骰子类玩法**不上线**线上。
- 长河令**不线上直售**、不可兑换现金；离园清零规则需公示。
- 会员卡权益**到店核销**激活；规则页需含限购/退款/有效期。
- 儿童溪降预约页强制展示年龄/身高条件并勾选确认。

> 建议在 CI/提审前跑一次敏感词扫描脚本，命中即拦截（T17）。

## 7. 命名
- 云函数：小驼峰动词（`createMemberOrder`）。
- 集合：小写下划线复数（`ling_ledger`）。
- 页面路由：`pages/<模块>/<页>/<页>`。

- [ ] 真机可跑，核心路径无 console 报错
- [ ] 涉及金额/库存的有并发/重复测试
