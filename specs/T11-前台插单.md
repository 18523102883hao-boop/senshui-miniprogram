# T11 · 前台插单 + 余位面板 ★下一阶段核心

- 状态：📄 下一阶段
- 依赖：T07, T10

## 目标
前台为现场客人手工占位并录入「上车号码」，与线上**同一库存池**，实时一致、防超卖。

## 页面（员工端，role: front/admin）
- 余位面板：按日期列出各场次 `remaining/capacity/status`（调 `listSessions`）。
- 插单：选场次 → 录入客人信息 + 上车号码 → 提交。

## 实现
- 插单**必须复用** `holdSeat`(T07)，与 C 端 `createBooking` 走同一 `remaining` 原子扣减 → 线上线下一个池，杜绝超卖。
- 写 booking 时标记 `source:'front'` + `boardingNo`（上车号码）。
- 云函数 `frontInsertBooking`：入口校验 `checkStaff` role∈{front,admin}。

## 验收
- [ ] 插单与线上同池扣减，余位实时一致
- [ ] 满场无法插单
- [ ] 上车号码正确记录并可在检票台账查看
- [ ] 并发（线上+插单）无超卖
