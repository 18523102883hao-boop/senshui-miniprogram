# T08 · 溪降预约 C 端流程 ★下一阶段核心

- 状态：📄 下一阶段
- 依赖：T07

## 目标
套票客户 4 步内完成预约，生成离线可出示的预约码。

## 流程
选日期 → 选场次（显示余位）→ 录入票号/核销凭证号 + 手机号（授权）→ 生成预约码（二维码，本地缓存离线可示）→ 订阅消息提前 30 分钟提醒集合。

## 数据模型 `bookings`
```
{
  _openid, sessionId, date, startTime,
  ticketNo,            // 票号/套票凭证号
  phone,
  code,                // 核销一次性 token（唯一，扫码核销用）
  boardingNo,          // 上车号码（前台插单/前台录入，T11）
  status: 'reserved',  // reserved | verified | canceled | released
  changeCount: 0,      // 改签次数（限 1）
  createdAt, updatedAt
}
```

## 云函数
- `createBooking`：调 `holdSeat`(T07) 占位 → 成功后写 booking + 生成 `code` → 返回预约信息。占位失败不写 booking。写 booking 失败要 `releaseSeat` 回补。
- `changeBooking`：改签，`changeCount < 1` 且开场前 X 分钟；先 `releaseSeat` 旧场再 `holdSeat` 新场（顺序与回补要处理好）。
- `cancelBooking`：取消并 `releaseSeat`。
- `getMyBookings`：我的预约列表（T15 用）。

## 规则边界
- 每凭证限约 1 场，可改签 1 次；开场前 X 分钟停止改签。
- 未到自动释放（定时触发器扫描过期 reserved → released + `releaseSeat`）。
- 儿童预约页**强制**展示年龄/身高安全条件并勾选确认。

## 离线
预约码 `code` 生成后 `wx.setStorageSync` 持久化，无网也能出示二维码给检票员。

## 验收
- [ ] 全流程 ≤4 步
- [ ] 离线可出示预约码
- [ ] 改签仅一次、开场前限时生效
- [ ] 儿童条件不勾选不可提交
