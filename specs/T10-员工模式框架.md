# T10 · 员工模式（工牌绑定 / 审批 / 角色路由）

- 状态：✅ 已实现
- 依赖：T04

## 已交付
| 文件 | 职责 |
|---|---|
| `pages/staff/entry` | 工牌绑定申请 + 已绑定角色展示 + 功能入口 |
| `pages/staff/verify` | 会员核销台（T14） |
| `cloudfunctions/checkStaff` | 校验 status='approved' 返回 role |
| `cloudfunctions/bindStaff` | 提交绑定申请（status='pending'） |

## 角色矩阵（staff.role）
| 角色 | 值 | 可用功能 |
|---|---|---|
| 前台 | front | 溪降余位/插单、会员核销、订单查询 |
| 溪降检票 | creek | 预约码核销、当场人数台账 |
| 酒吧/小卖部 | bar | 接单、配送、租赁押金核销、领酒核销 |
| 管理员 | admin | 员工审批、场次/内容配置、数据导出 |

## 审批
V1 无自研后台：管理员在**云开发控制台**手动把 staff 记录 `status` 改为 `approved` 并设 `role`。V3 再建 Web 审批看板。

## 安全
- 未审批不可见任何员工页；核销/插单云函数内**二次校验角色**（不能只靠前端隐藏）。

## 验收
- [ ] 未授权用户不可见/不可调用任何员工功能
- [ ] 审批后角色正确路由
