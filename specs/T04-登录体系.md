# T04 · 登录 / 静默注册 / 手机号延后授权

- 状态：✅ 已实现
- 依赖：T02

## 已交付
| 文件 | 职责 |
|---|---|
| `cloudfunctions/login` | wx.login 换 openid，静默注册/更新 `users` |
| `cloudfunctions/bindPhone` | 新版 getPhoneNumber(code) 换手机号写入 `users` |
| `miniprogram/utils/auth.js` | `silentLogin` / `bindPhone` / `ensureLogin` |
| `miniprogram/app.js` | onLaunch 静默登录，`app.loginReady` 暴露 Promise |

## 接口契约
- `login()` → `{ openid, user:{ id, phone, nickName, avatarUrl } }`
- `bindPhone({ code })` → `{ phoneMask }`（如 `138****8888`）

## 关键点
- 新用户 3 秒内进首页（静默登录不阻塞浏览）。
- 手机号授权**仅在**预约/下单/个人中心触发（`<button open-type="getPhoneNumber">`），不在进入即索取。
- 云函数内 `add` 需手动写 `_openid`（客户端自动写入行为在云端不生效）。
