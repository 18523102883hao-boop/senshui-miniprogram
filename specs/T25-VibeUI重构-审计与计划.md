## 一、现状审计

### 1.1 路由与页面树（23 页，零自定义组件）

| 分组 | 页面 | 备注 |
|---|---|---|
| Tab×3 | index(向导) / ling(长河令) / mine(我的) | 原生 tabBar，`custom:false` |
| C端内容 | catalog / creek-notice / upgrade-info / member/detail / member/card / coupon / order / ling/mycode | 均为浅色卡片流 |
| C端隐藏 | ticket / booking/list / booking/detail / booking/create | 功能未开放，入口已隐藏 |
| 交易 | pay/upgrade（补差价支付） | 已验证支付逻辑，**不动** |
| 员工端 | staff/entry / verify / creek / charge / charge-summary / ling-exchange / maps | 内部工具，优先级低 |

组件树：**无 components 目录**——所有 UI 是页面级 WXML + `app.wxss` 全局类（`sr-card`/`sr-btn` 等），复用靠类名不靠组件。

### 1.2 样式令牌现状 vs 交付包规范

| 维度 | 现状 | 规范 | 差距 |
|---|---|---|---|
| 背景 | `#F5F1E9` | `bg-light #F6F4F0` | 值近似，需统一替换 |
| 主色 | `#2A4D3A` | `forest #244B36` | 同上 |
| 强调 | 朱砂 `#B23A2E` | `coral #F07055`（交易CTA）| **语义变化**：现在朱砂身兼金额/CTA/危险多职，需按纪律拆分 |
| 金色 | `#B8860B` | `gold #D5A43A` 仅限令/奖励/会员 | 需收敛用途 |
| 深色主题 | **无** | `#121212`/`#1C1C1E` 长河令专用 | 全新建设 |
| 圆角 | 20/12 两档 | 24/32/40/56 四档 | 扩档 |
| 阴影 | 1 种全局用 | 仅重点卡片 | 收敛 |

结论：色系气质一致，**保留 `--sr-*` 变量名、整体替换值并新增令牌**（coral/dark 系/success 等），改一处 `app.wxss` 全站生效，不用改类名。

### 1.3 图标混用问题（违反规范红线）

- 页面内图标 = **汉字字符**（令/寿/购/酒/服/租）+ Unicode 符号（✓ ✕ › #）
- tabBar = 本次会话临时生成的 6 张 PNG（与交付包 tabbar 图标功能重复，应替换为交付包版）
- 无 iconfont、无 emoji（这点达标）
- **风险：图标全量 2.5MB > 主包 2MB 上限 → 只按 icon-map.json 拷贝实际用到的子集（预计 40~60 个，约 500KB）**

### 1.4 交互现状（需要改 UX 而非换皮的清单）

| 规范要求 | 现状 | 定性 |
|---|---|---|
| 按压态 scale + hover-class | 全站几乎无 | **UX 缺失**，全局补 |
| 触觉反馈 haptic | 无 | **UX 缺失**，用交付包 `haptics.js` |
| 长河令深色沉浸页 | 浅色卡片流 | **重构**：弥散光资产卡 + 悬赏列表整行点击 |
| 自定义 tabBar 双主题 | 原生 tabBar | **重构**：custom-tab-bar + 浅/深随页切换 + blur 降级 |
| 地图半屏卡 | 自制全屏查看器 | **改造**：静态图先做"点击→半屏卡（简介/导航/详情）"；POI 级交互**没有坐标数据**，留待地图数据就绪 |
| 横滑选择 | catalog 分类是普通 tab | 改横向 scroll-view + 吸附 |
| 长按预览/领取 | 无 | 长河令兑换项上做长按预览；"长按领令"待有领令业务再上 |
| 首屏状态卡（开放/天气/水位）| **无数据源** | 见"待拍板问题 1" |
| 时间线活动表 | 已有雏形（固定日程）| 换皮升级即可 |
| 黑金会员卡 | 已有雏形（sr-goldcard 流光）| 按规范精修即可 |

### 1.5 工程约束确认

- 支付/订单/核销云函数逻辑**零改动**（约束七），重构只动 WXML/WXSS/JS 展示层
- 动画只用 transform/opacity；滚动列表禁 blur/大阴影（低端安卓）
- 不引入 Tailwind/外链字体/运行时 iconfont（与此前结论一致）
- iCloud 目录风险已由 git 兜底：分支 `vibe-ui`，每批 commit
