# T14 · 会员权益核销（令 / 酒 / 85 折券）

- 状态：✅ 已实现
- 依赖：T10, T13

## 已交付
| 文件 | 职责 |
|---|---|
| `pages/member/card` | 会员码展示 + 权益状态 + 退款入口 |
| `pages/staff/verify` | 员工核销台：扫码 → 拉权益 → 逐项核销 |
| `cloudfunctions/getMemberCard` | 本人卡与权益状态 + 退款资格 |
| `cloudfunctions/getMemberForVerify` | 员工按会员码拉权益（可核销标记） |
| `cloudfunctions/verifyBenefit` | 核销令/酒/券，事务防重复 + 留痕 |

## 权益核销规则
| 类型 | benefitType | 行为 |
|---|---|---|
| 长河令 | `ling` | 一次性发 1000 令：`ling_accounts` 累加 + `ling_ledger` 流水；标 granted=true |
| 酒 | `wine` | 每次核销发 1 瓶，累计至 total(2)；granted 计数 |
| 85折券 | `coupon` | 一次性发 5 张 `discount_85` 入 `coupons`；标 granted=true |

## 关键保障
- 员工权限：`verifyBenefit` 内 `requireStaff` 校验 approved。
- 防重复：事务内读 benefits 判断，已发放抛错回滚（返回 409）。
- 全量留痕：每次核销写 `verifications`（含 staffOpenid/staffName）。
