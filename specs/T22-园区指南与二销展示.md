# T22 · 园区指南 · 二销商品/服务查看 + 首页重排

- 状态：✅ 代码完成 · 云函数已部署 · 目录数据已灌入
- 依赖：notices 集合

## 目标

功能收窄（溪降/购票暂隐）后首页偏空。补齐「客户查看」类内容，让客户知道园区提供哪些商品、
服务、以及溪降信息，并重排首页填充空白。

## 交付

| 模块 | 说明 |
|---|---|
| `pages/catalog/catalog` | 商品与服务：酒吧 / 小卖部 / 装备租赁 / 服务（露营风扇）tab 切换 |
| `pages/creek-notice/creek-notice` | 溪降须知：开放时间 10:00–16:30 + 费用/装备/安全/退票 |
| `pages/upgrade-info/upgrade-info` | 补差价升级说明（客户查看版，实际补差走前台 T20 收款） |
| `pages/index`（重排） | 会员卡主推卡片 + 「园区指南」三格入口 + 今日活动 + 园区地图 |
| `cloudfunctions/seedCatalog` | 一次性写入商品目录到 `notices(type:'catalog')`（幂等，改价重跑） |
| `cloudfunctions/getCatalog` | 读取目录供展示 |

## 数据

- 目录存 `notices(type:'catalog').sections`：bar / store / rental / service 四区；价格单位=元（展示用）。
- 酒吧价目、小卖部零售 + 租赁、露营风扇服务均来自商家提供的价目表/海报。
- 溪降须知、补差价说明为稳定文案，直接写在页面。

## 后续可改

- 改价：让我重跑 `seedCatalog`（改 SECTIONS）或在云开发控制台 `notices` 里改。
- 溪降/购票恢复：`index.js` routes 与页面均保留，取消注释即可。
