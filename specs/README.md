# 森水长河小程序 · 开发规格（Spec）索引

本目录把 PRD 的 T01–T19 拆成**可独立开发的规格文档**。每份 spec 自带目标、接口契约、数据结构、验收标准，其他 AI 工具（Cursor / Trae / CodeBuddy / Copilot / fable 等）可按单个文件独立开发。

## 使用方式
1. 先读 [`_conventions.md`](./_conventions.md)（全局约定：返回格式、身份、金额、合规词表）——**所有任务通用，必读**。
2. 再读具体任务 spec。标注「📄待开发」的按 spec 实现；「✅已实现」的对照代码做联调/完善。
3. 数据结构以 [`../docs/数据模型.md`](../docs/数据模型.md) 为准。
