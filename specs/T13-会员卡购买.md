# T13 · 会员卡购买（支付 / 限购 / 订单）

- 状态：✅ 已实现
- 依赖：T02, T04

## 已交付
| 文件 | 职责 |
|---|---|
| `pages/member/detail` | 权益展示 + 9.9 购买 + 购买须知 |
| `cloudfunctions/createMemberOrder` | 限购校验 + 复用未支付单 + 云支付统一下单 |
| `cloudfunctions/payCallback` | 支付回调**幂等发卡**（事务 + 二次限购保护） |
| `cloudfunctions/refundMember` | 7 天无理由退款（未核销任一权益） |

## 支付链路
`createMemberOrder` → `wx.requestPayment` → 微信回调 `payCallback`（建卡） → 卡包可见。

## 关键保障
- **限购 1 张**：下单前查 + 回调事务内二次查（并发/重复支付防第二张卡，重复支付标 `paid_dup`）。
- **幂等**：回调可能重复，已处理订单直接 ack；`orders.outTradeNo` 唯一索引兜底。
- **发卡内容**：建 `members`（active，权益初始未发），令/酒/券在核销时发（T14）。

## 部署依赖
- 云开发关联微信支付；`createMemberOrder`/`refundMember` 配环境变量 `SUB_MCH_ID`。
- 价格 990 分（9.9 元）在 `createMemberOrder` 常量，改价改此处 + `utils/const.js`。
