Issues 和 specs 作为 markdown 文件存放在 `.scratch/` 中。详见 `docs/agents/issue-tracker.md`。

使用五个 canonical triage roles：`needs-triage`、`needs-info`、`ready-for-agent`、`ready-for-human`、`wontfix`。详见 `docs/agents/triage-labels.md`。

### Domain docs

Single-context 布局：根目录 `CONTEXT.md` + `docs/adr/`。详见 `docs/agents/domain.md`。
